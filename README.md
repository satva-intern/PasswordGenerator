# Advanced Password Generator & Strength Checker

This is a Streamlit app that generates strong, customizable passwords and checks their strength visually.

## Features

- Choose password length and character types (uppercase, lowercase, digits, special characters)
- See password strength as a progress bar and color label (red/yellow/green)
- Confirms if password meets your selected rules
- Easy-to-use sidebar controls

## Getting Started

1. **Clone this repository:**
    ```
    git clone https://github.com/yourusername/your-repo.git
    cd your-repo
    ```

2. **Install Streamlit:**
    ```
    pip install streamlit
    ```

3. **Run the app:**
    ```
    streamlit run app.py
    ```

4. Open [http://localhost:8501](http://localhost:8501) in your browser.

## Usage

- Set your password requirements in the sidebar
- Click "Generate Password"
- View the password and its strength in the main area
